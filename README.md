# 🔗 LinkSwift

A high-performance, full-stack URL shortening platform. This project demonstrates a decoupled architecture using **Next.js 16** for a seamless frontend experience and **Golang** for a robust, scalable backend.

## 🚀 Architecture Highlights

- Next.js 16 Frontend
- Server Actions
- Zod Validation
- Golang Backend
- Admin Dashboard

## ✨ Features

- **Fast Redirection**: Short links resolved in milliseconds.
- **Admin (WIP)**: Secure login to access management tools.
- **Responsive Design**: Mobile-first UI built with Tailwind CSS.

## 🛠️ Tech Stack

### Frontend
- **Framework**: [Next.js 16](https://nextjs.org) (App Router)
- **Validation**: [Zod](https://zod.dev)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)

### Backend
- **Language**: [Go (Golang)](https://go.dev)
- **API**: REST
- **Database**: PostgreSQL
- **Authenticato (WIP)**: JWT Token
- [repo](https://github.com/ElvisCtf/url-shortener-go)

## 🚦 Getting Started

### Prerequisites
- Node.js 20.9+

1. run the development server:

```bash
npm run dev
```

2. Copy .env.example and create .env.local

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
